## Architecture Summary

```
Total Parameters: 99,167
├─ Hidden Layer 1: 207×256 + 256 = 53,248
├─ Hidden Layer 2: 256×128 + 128 = 32,896
└─ Output Layer: 128×95 + 95 = 12,255

Parameter Efficiency: 202 parameters per training sample (99,167 / 490 samples)
```

## Key Design Decisions

1. **Simple MLP Architecture**: 
   - Chosen over complex CNN due to small dataset (490 samples)
   - Avoids over-parameterization (old model: 792K params vs new: 99K params)

2. **Two Hidden Layers**:
   - Layer 1 (256): Expands features, learns complex combinations
   - Layer 2 (128): Compresses representation, refines predictions
   - Progressive reduction prevents overfitting

3. **Batch Normalization**:
   - Stabilizes training by normalizing layer inputs
   - Allows higher learning rates
   - Reduces internal covariate shift

4. **ReLU Activation**:
   - Non-linear, computationally efficient
   - Helps with vanishing gradient problem
   - Sparse activations (natural regularization)

5. **Dropout (0.3)**:
   - Critical for small dataset
   - Randomly drops 30% of neurons during training
   - Prevents co-adaptation of features

6. **No Output Activation**:
   - Regression task requires unbounded output
   - Gain values can be negative (-13.5 to 20.2 dB)
   - Model learns to predict raw normalized values

## Training Configuration

```
Optimizer: Adam
  - Learning Rate: 0.001
  - Weight Decay: 1e-5
  - Gradient Clipping: max_norm=1.0

Scheduler: ReduceLROnPlateau
  - Mode: min (monitor validation loss)
  - Factor: 0.5 (reduce LR by half)
  - Patience: 20 epochs
  - Min LR: 1e-6

Training:
  - Epochs: 200 (with early stopping)
  - Batch Size: 32
  - Validation Split: 20%
  - Early Stopping Patience: 50 epochs
  - Loss: MaskedMSE (only on unmasked channels)

Regularization:
  - Dropout: 0.3 on all hidden layers
  - Batch Normalization: All linear layers
  - Weight Decay: 1e-5
  - Gradient Clipping: 1.0
  - Early Stopping: 50 epochs

Target Normalization:
  - Per-channel standardization
  - Mean: ~4.21 dB, Std: ~7.81 dB
  - Applied during training, reversed for prediction
```

## Masked Loss Function

The model uses a masked MSE loss that only computes loss on unmasked channels:

```
MaskedMSE = Σ((pred - target)² × mask) / Σ(mask)

Where:
- pred: Model predictions (B, 95)
- target: Ground truth labels (B, 95)
- mask: Binary mask (B, 95) where 1=unmasked, 0=masked
- Loss is computed only on channels where mask=1
```

This is critical because:
- Training data contains 75.9% zeros (masked channels)
- Standard MSE would be dominated by zeros
- Masked loss focuses learning on actual gain values (17-18 dB)
