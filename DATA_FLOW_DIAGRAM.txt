## Key Processing Steps

### 1. Feature Preprocessing
- **Spectral Features (95)**: Input power spectrum, standardized to z-scores
- **Scalar Features (4)**: EDFA configuration parameters, standardized
- **Categorical Features (3)**: One-hot encoded (~6-9 dimensions)
- **Mask Features (95)**: Binary activation patterns, passed through unchanged

### 2. Neural Network Forward Pass
- **Input Layer**: 207 → 256 dimensions
  - Linear transformation with Xavier initialization
  - Batch normalization for stable training
  - ReLU activation for non-linearity
  - Dropout (0.3) for regularization

- **Hidden Layer 2**: 256 → 128 dimensions
  - Linear transformation with Xavier initialization
  - Batch normalization for stable training
  - ReLU activation for non-linearity
  - Dropout (0.3) for regularization

- **Output Layer**: 128 → 95 dimensions
  - Linear transformation with Xavier initialization
  - No activation (regression task)
  - Outputs normalized gain predictions

### 3. Target Normalization (During Training)
- **Purpose**: Stabilize training by normalizing target values
- **Method**: Per-channel standardization
  - mean = 4.21 dB (average across all channels)
  - std = 7.81 dB (average across all channels)
- **Application**: Applied to training labels before loss computation
- **Reversal**: Applied to predictions after model output

### 4. Masked Loss Function
- **Purpose**: Focus learning on unmasked channels only
- **Formula**: MaskedMSE = Σ((pred - target)² × mask) / Σ(mask)
- **Why Critical**: Training data has 75.9% zeros (masked channels)
  - Standard MSE would be dominated by zeros
  - Model would learn to predict values near zero
  - Masked loss ensures learning on actual gain values (17-18 dB)

### 5. Prediction Denormalization
- **Purpose**: Convert normalized predictions back to original scale
- **Formula**: pred_original = pred_normalized × std + mean
- **Result**: Predictions in dB range (-13.5 to 20.2)

### 6. Mask Application (Submission)
- **Purpose**: Zero out predictions for masked channels
- **Formula**: final_pred = pred × mask
- **Effect**: 
  - Unmasked channels: Keep predicted gain (13-20 dB)
  - Masked channels: Set to 0.0

## Key Design Decisions

1. **Simple MLP Architecture**: 
   - Chosen over complex CNN due to small dataset (490 samples)
   - Avoids over-parameterization (87.5% fewer parameters than old model)

2. **Progressive Dimensionality Reduction**:
   - Input (207) → Hidden 1 (256) → Hidden 2 (128) → Output (95)
   - Expansion then compression helps learn complex patterns
   - Final reduction prevents overfitting

3. **Batch Normalization**:
   - Stabilizes training by normalizing layer inputs
   - Allows higher learning rates
   - Reduces internal covariate shift

4. **ReLU Activation**:
   - Non-linear, computationally efficient
   - Helps with vanishing gradient problem
   - Sparse activations (natural regularization)

5. **Dropout (0.3)**:
   - Critical for small dataset
   - Randomly drops 30% of neurons during training
   - Prevents co-adaptation of features

6. **Masked Loss Function**:
   - Most critical design decision for this problem
   - Ensures model learns to predict actual gain values
   - Prevents model from being dominated by masked channels

7. **Target Normalization**:
   - Stabilizes training by normalizing target values
   - Allows model to learn from normalized targets
   - Reversed for final predictions
