## Key Processing Steps

### 1. Spectral Feature Processing
- **Input**: 95 frequency bins representing input power spectrum
- **CNN Operations**: 
  - Layer 1 (k=7): Captures broad spectral trends
  - Layer 2 (k=5): Captures medium-scale patterns
  - Layer 3 (k=3): Captures fine-grained details
  - Layer 4 (k=3): Refines features
- **Attention Mechanisms**:
  - Spectral Attention: Learns which frequency channels are important
  - Multi-Head Attention: Captures relationships between all channels

### 2. Scalar Feature Processing
- **Input**: Configuration parameters (gain, tilt, power) + categorical + mask
- **MLP Operations**:
  - Layer 1: Expands to 256 dimensions, learns complex combinations
  - Layer 2: Compresses to 128 dimensions, refines representations
- **Purpose**: Captures EDFA configuration effects on gain

### 3. Cross-Modal Fusion
- **Purpose**: Combines spectral and scalar information
- **Operations**:
  - Projection: Both branches projected to 256 dimensions
  - Concatenation: Creates joint 512-dim representation
  - Fusion MLP: Learns interactions between modalities
  - Cross-Attention: Allows features to attend to each other
- **Output**: Integrated 256-dim representation

### 4. Decoding
- **Purpose**: Maps fused representation to gain spectrum
- **Operations**:
  - Layer 1: Maintains 256 dims, transforms for prediction
  - Layer 2: Reduces to 128 dims, refines predictions
  - Output: 95 gain values (one per frequency channel)

## Key Design Decisions

1. **Dual-Branch Architecture**: Separates spectral and scalar processing for better feature extraction

2. **Multi-Scale CNN**: Different kernel sizes (7, 5, 3) capture patterns at different frequency scales

3. **Attention Mechanisms**: 
   - Spectral attention provides interpretability
   - Multi-head attention captures global context

4. **Cross-Modal Fusion**: Allows interaction between spectral and scalar features

5. **Progressive Dimensionality**: 
   - CNN expands channels (1→32→64→128)
   - MLP expands then compresses (105→256→128)
   - Fusion maintains 256 dims
   - Decoder compresses to output (256→128→95)

6. **Strong Regularization**: Critical for small dataset (490 samples)
